# Mouse Hands

Python Script that lets you control your Mouse with your hands.
Touch Index and Thumb to Left Click.
Touch Pinky and Thumb to Right Click.
Touch Index and Middle to Scroll.

## To Use
Copy the Repo and install the necessary packages.


```bash
pip install -r requirements.txt
python mouse_hands.py
```

It is very basic at the moment, but if there are any suggestions, I would be more than happy to apply them!
